# 🤖 LEGI V4 M-HO

LEGI V4 M-HO là một dự án bot Messenger được xây dựng trên nền tảng Node.js với mục tiêu mang lại hiệu năng ổn định, dễ mở rộng và dễ quản lý.

## ✨ Tính năng

- 🚀 Tốc độ xử lý nhanh.
- 🔒 Hỗ trợ đăng nhập bằng Cookie.
- 📦 Quản lý module linh hoạt.
- 🤖 Hệ thống lệnh mở rộng.
- 💬 Tự động xử lý sự kiện Messenger.
- 🛡️ Tăng cường độ ổn định khi hoạt động.
- ⚙️ Dễ dàng cấu hình và triển khai.

## 📁 Cấu trúc

```
LEGI-V4-M-HO/
├── modules/          # Các lệnh
├── events/           # Sự kiện
├── includes/         # Thư viện hỗ trợ
├── utils/            # Tiện ích
├── config.json       # Cấu hình
├── package.json
└── index.js
```

## 📦 Yêu cầu

- Node.js 20+
- npm hoặc yarn

## 🚀 Cài đặt

```bash
git clone https://github.com/devminhtri15022/LEGI-V4-M-HO-.git

cd LEGI-V4-M-HO-

npm install

npm start
```

## ⚙️ Cấu hình

Chỉnh sửa file:

```
config.json
```

để thiết lập:

- Cookie
- Prefix
- Admin
- Các thông số hệ thống

## 📌 Lưu ý

- Chỉ sử dụng cho mục đích học tập và nghiên cứu.
- Không sử dụng vào các hoạt động vi phạm điều khoản của nền tảng hoặc pháp luật.
- Luôn cập nhật phiên bản mới để có trải nghiệm tốt nhất.
